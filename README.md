# 🎨 React Studio Builder

**Build React without writing a single line of code.**  
Studio is a visual drag‑and‑drop editor that outputs production‑ready React JSX & CSS. Compose layouts, style every detail, and export clean code instantly.

👉 Try it now: [React Studio Builder](https://react-studio-builder.vercel.app/)

---

## 🚀 Features

- ⬡ **Infinite Canvas** – Zoom, pan, and build at any scale. Your workspace never runs out of room.  
- ◈ **Live Inspector** – Every CSS property, spacing box, and animation preset in one side panel.  
- ◻ **Layers Panel** – See the full component tree. Drag to reorder, click to select, delete with a keystroke.  
- ⬟ **Undo / Redo** – Full history stack with keyboard shortcuts. Experiment freely without fear.  
- ◇ **Export JSX + CSS** – One‑click export generates clean, readable React code.  
- ◈ **No Account Needed** – Open the Studio, start building immediately. Zero sign‑up, zero friction.  

---

## 🛠 How It Works

### 01 – Pick a Component  
Browse Layout, Text, Forms, and Media from the left shelf. Every primitive you need is one click away.

### 02 – Drag & Drop  
Place elements onto the infinite canvas. Nest them, reorder via the Layers panel, and compose in real time.

### 03 – Inspect & Style  
Select any element and tune padding, color, typography, animations, and more inside the Inspector.

### 04 – Export Clean Code  
Hit **Export** — get production‑ready React JSX and CSS, ready to paste directly into your project.
